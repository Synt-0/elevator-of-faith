# elevator-of-faith
A short psychological  story about guilt, memory, and a mysterious elevator.

About

Elevator of Faith is a single-player, narrative-driven psychological   game following Elias Ward a man trapped in a mysterious elevator that takes him through floors that should not exist.

Features

story-driven psychology

multiple choices that shape future

2 endings

dark, pixel art  visuals
